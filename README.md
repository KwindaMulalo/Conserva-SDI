# Conserva

Conserva is a geoportal designed for managing and presenting geospatial information on protected areas in South Africa.

The project focuses on conservation and protected area data, including national parks, municipal protected areas, transnational parks, biodiversity priority areas, rivers, and related spatial datasets.

The portal provides a landing page and access to an interactive web map for viewing and exploring protected area information.

The portal is available from `index.html`.
